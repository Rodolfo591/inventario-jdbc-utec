# Sistema de Gestión de Inventario - JDBC & H2

Proyecto académico desarrollado para la asignatura de **Programación III** en la **Universidad Tecnológica de El Salvador (UTEC)**.

## 📋 Descripción
Aplicación de consola Java desarrollada con arquitectura DAO (Data Access Object) para la gestión del ciclo CRUD de un inventario de productos, persistida en una base de datos H2 mediante JDBC.

## 👥 Integrantes del Equipo y Contribuciones
* **Rodolfo (Líder / Integrante 1):** Estructura base del proyecto, menú interactivo y módulo de inserción y lectura (`Create` / `Read`).
* **Pablo (`pabloECV` / Integrante 2):** Módulo de actualización de productos (`Update`).
* **Integrante 3:** Módulo de eliminación de productos (`Delete`).

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java (JDK 17+)
* **Gestor de Dependencias:** Apache Maven
* **Base de Datos:** H2 Database Engine (Modo archivo)
* **Persistencia:** JDBC con Patrón DAO
* **Control de Versiones:** Git & GitHub (Git Flow con Pull Requests)
